# 安装方法

[← 返回首页](../README.md)

## 开始前请确认

- 电视或盒子是安卓 9 及以上。LG（webOS）、三星（Tizen）不是安卓系统，不能用。
- 电视和手机连同一个 Wi-Fi，并且都能上网。
- 安装包地址：`http://106.54.222.166:8686/download/tvquiz.apk`

手机网页不能把应用直接装到电视上。请从下面选一种方法。

## 方法 1：U 盘安装（最简单）

1. 用电脑下载安装包 [tvquiz.apk](http://106.54.222.166:8686/download/tvquiz.apk)。
2. 把安装包复制到 U 盘。
3. 把 U 盘插到电视或盒子上。
4. 用电视的「文件管理」（有的叫「媒体中心」「本地播放」）找到 tvquiz.apk，点开安装。
5. 如果提示「禁止安装未知来源应用」，到电视「设置」里打开「未知来源」或「安装未知应用」，再装一次。

电视读不出 U 盘时：在电脑上把 U 盘格式化成 **FAT32**，再复制安装包（格式化会清空 U 盘）。还读不出，换 exFAT 或 NTFS 再试。

## 方法 2：电视直接下载

1. 在电视上打开浏览器，或者能输入网址下载的应用（例如「下载器」类应用）。
2. 输入地址：`http://106.54.222.166:8686/download/tvquiz.apk`
3. 下载完成后，点开安装。

## 方法 3：电脑 adb 安装（什么电视都能试）

适合不让装外来应用的电视。电脑要先装好 adb（Android 平台工具）。

1. 在电视上打开「开发者选项」，再打开「USB 调试」和「网络调试」。各品牌的位置见下面的[品牌表](#各品牌打开开发者选项)。
2. 在电视「设置 → 网络」里查到电视的 IP 地址，例如 `192.168.1.23`。
3. 电脑和电视连同一个 Wi-Fi，然后依次执行：

   ```
   adb connect 电视IP:5555
   adb install -r tvquiz.apk
   adb shell appops set com.gebilaozhongyi.tvquiz SYSTEM_ALERT_WINDOW allow
   adb shell am start -n com.gebilaozhongyi.tvquiz/.MainActivity
   ```

4. 第一次连接时，电视会问「允许 USB 调试吗？」。用遥控器勾选「一律允许」，再点「允许」。不点允许，后面的命令都会失败。
5. 装好后，建议回到开发者选项，关掉「网络调试」。这样家里其他设备不能再连这台电视。以后升级时再打开。

### 各品牌打开开发者选项

菜单名称和位置随型号和系统版本变化。下表是常见位置。找不到时，在网上搜「品牌 + 型号 + 开发者选项」。

| 品牌 | 打开开发者选项 | 还要打开 |
|---|---|---|
| 通用安卓电视、电视盒子、索尼 | 设置 → 设备偏好设置（或「关于」）→ 连按「版本号」或「内部版本号」7 次 | USB 调试、网络调试 |
| 小米 / Redmi | 设置 → 关于 → 连按「产品型号」7 次 | USB 调试、**USB 安装** |
| TCL / 雷鸟 | 设置 → 关于 → 本机信息，用遥控器依次按「上、下、左、右」，在底部「更多」里找 ADB（部分机型） | ADB 调试 |
| 海信 / Vidda | 「关于」页面里找开发者选项。部分机型没有这个入口 | USB 调试、网络调试 |
| 创维 / 酷开 | 「关于」页面或单独的开发者菜单 | USB 调试、网络调试 |
| 其他品牌 | 先试「关于」页面里连按版本号 7 次 | USB 调试、网络调试 |

返回上一级菜单，就能看到「开发者选项」。

### adb 的三种连接方式

| 方式 | 电视上打开 | 电脑上执行 |
|---|---|---|
| **无线**（推荐） | USB 调试 + 网络调试 | `adb connect 电视IP:5555` |
| **有线** | USB 调试。用 USB 双公头线（A 口对 A 口）连接电脑和电视 | `adb devices`，看到设备后直接 `adb install` |
| **配对码**（安卓 11 及以上的「无线调试」） | 开发者选项 → 无线调试 → 使用配对码配对设备 | `adb pair 电视IP:配对端口`，输入电视上的 6 位码；再执行 `adb connect 电视IP:连接端口` |

配对码方式有两个端口：配对端口在配对码弹框里，连接端口在「无线调试」页面上。两个端口不同，每次打开都可能变。

### 检查连接

执行 `adb devices`，看电视那一行的状态：

| 状态 | 意思和办法 |
|---|---|
| `device` | 连接正常，可以安装。 |
| `unauthorized` | 电视上没有点「允许」。看电视屏幕上的弹框，点「允许」。没有弹框：电视上关掉再打开网络调试，电脑上执行 `adb kill-server`，再 `adb connect`。还不行：在开发者选项里点「撤销 USB 调试授权」，再连一次。 |
| `offline` 或连接被拒绝 | 网络调试没有打开、IP 地址不对，或电脑和电视不在同一个网络。逐项检查后再连。 |

## 方法 4：让 AI 帮你装

如果你的电脑上有能执行命令的 AI 助手，把 [AI 安装指南](ai-install.md) 复制给它。它会下载、连接电视、安装、授权。你只要在电视上按一次「允许」。

## 不同品牌的电视

| 情况 | 建议 |
|---|---|
| 能找到「未知来源」开关 | 用方法 1 或方法 2。 |
| U 盘打开后提示「禁止安装」，或找不到「未知来源」开关 | 这个品牌限制安装外来应用（部分海信、创维机型是这样）。用方法 3（电脑 adb）或方法 4（AI）。 |
| 小米 / Redmi 电视 | 用 adb 安装时，开发者选项里还要打开「USB 安装」。 |
| 找不到开发者选项 | 见上面的[品牌表](#各品牌打开开发者选项)。 |
| 电视盒子 | 和电视相同，按上面的方法装。 |

## 装好后：允许「显示在其他应用上层」

娃爱答题要在别的应用上面弹出题目，所以需要这个权限。没有它，题目弹不出来，电视首页会显示「缺少悬浮窗权限」。

1. 打开电视「设置 → 应用 → 特殊应用权限 → 显示在其他应用上层」（各品牌路径不同）。
2. 找到「娃爱答题」，选「允许」。
3. 找不到这个菜单：用电脑执行

   ```
   adb shell appops set com.gebilaozhongyi.tvquiz SYSTEM_ALERT_WINDOW allow
   ```

## 扫码和配对

1. 在电视上打开「娃爱答题」。首页有一个二维码。
2. 手机连上和电视相同的 Wi-Fi。
3. 用手机相机扫这个二维码。手机浏览器会打开管理页面。
4. 输入电视上显示的 6 位配对码。配对码 10 分钟内有效，过期后电视会显示新的。
5. 设置一个 6 位家长密码。请记住它。连续输错 5 次，要等 5 分钟才能再试。

要用内测版：先到家长群领取免费的内测激活码（[官网](http://106.54.222.166:8686/#group) 上扫码进群），再在管理页面打开「我的 → 激活码」输入。

## 故障排查

| 现象 | 原因和办法 |
|---|---|
| 扫码后页面打不开 | ① 手机和电视要连同一个 Wi-Fi。手机不要用流量，也不要连访客网络。② 关掉手机上的 VPN 或代理，再扫一次。③ 用手机相机或浏览器扫码。别的应用扫码打不开时，换相机扫。 |
| 以前能打开，现在打不开 | 电视的 IP 地址可能变了（重启路由器后常见）。回到电视上的「娃爱答题」首页，用手机重新扫二维码。 |
| 页面显示「暂时打不开管理页面」 | 页面已经连上电视，但手机没能从网上加载管理程序。确认手机能上网，然后点「刷新」。 |
| 苹果手机用第三方浏览器打不开 | 系统会问是否允许查找本地网络上的设备，请选允许。也可以用 Safari 打开。 |
| 配对码不对或过期 | 配对码 10 分钟内有效。看电视上最新的配对码，重新输入。 |
| 到时间了不出题 | ① 检查是否允许了「显示在其他应用上层」。② 检查管理页面里答题是否开着。 |
| 过一段时间就不出题了 | 电视的清理功能可能关掉了「娃爱答题」。在电视管家或清理工具里，把它加入白名单，允许自启动和后台运行。然后打开一次「娃爱答题」。有的电视用遥控器待机时也会清理后台，待机唤醒后请检查一次。 |
| 电视重启后不出题 | 应用会随电视开机启动。有的电视会拦截自启动，请在电视设置里允许「娃爱答题」自启动，或开机后手动打开一次。 |
| 其他问题 | [提交问题报告](https://github.com/tv-quiz/LoveStudyOnTV/issues)。请写上电视品牌、型号和出错的画面。 |
